The problem

The Portal is where creators manage an AR experience. One part is indoor navigation: importing a scanned map and placing pins for visitors. Creators are not developers.

What I found

A map needs a NavMesh, then a 3D mesh or a 2.5D map, and any of them can be missing or fail to load. Most of the work was deciding what the editor shows in each case.

The solution

Screen with numbered notes

1 Normal state

Each map lists the assets it has, with an import button for each.

2 Empty state

No 3D mesh and no 2.5D map: the row says there is nothing to import.

3 Error state

If a refresh fails, the last list stays, marked as possibly out of date.
